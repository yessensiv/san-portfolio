# SAN — портфолио

[Открыть сайт](https://san-portfolio-one.vercel.app/) · [Все работы](https://san-portfolio-one.vercel.app/work)

Персональное портфолио сайтов, приложений и графического дизайна. Чёрный фон, лаймовые акценты, плавный скролл и анимированная композиция SAN на canvas.

## Возможности

- Русский язык по умолчанию, переключение RU / KZ / ENG с сохранением выбора.
- Галерея с разделами «Сайты», «Приложения и ИИ», «Графический дизайн».
- Карточки проектов со ссылками на сайты и исходники, адаптивная версия для телефона.
- Полноэкранный просмотр дизайн-постеров; закрытие кнопкой, по фону или Escape.
- Плавная прокрутка, волновая анимация SAN, звуковые эффекты и переключатель звука.
- Поддержка системной настройки уменьшения анимации.

## Работы

**Сайты:** DentaLux, ENT Math, Zaga Zaga, [AST Group](https://ast-group-website.vercel.app/), [LeadFlow](https://saa-s-bojp.vercel.app/).

**Приложения и ИИ:** Flow — Android-приложение для загрузки медиа; DocMind — Telegram-помощник для работы с документами.

**Графический дизайн:** «Дизайн под ключ», Porsche 911 GT3 RS, Design Level Up, Darth Vader.

## Технологии

Next.js 16, React 19, TypeScript, GSAP, Lenis, HTML/CSS и Canvas API. Маршруты и мост анимации написаны на TypeScript; существующие визуальные модули — на JavaScript.

## Локальный запуск

Нужны Node.js 20.9+ и npm.

```sh
git clone https://github.com/yessensiv/san-portfolio.git
cd san-portfolio
npm ci
npm run dev
```

Откройте http://127.0.0.1:3000. Галерея доступна по адресу `/work`.

## Проверка и production

```sh
npm run typecheck
npm run build
npm start
```

`npm run build` сначала собирает статические ресурсы и скрипты, затем создаёт production-сборку Next.js. Для публикации на Vercel используется конфигурация `vercel.json`.

## Где редактировать

| Файл / каталог | Назначение |
| --- | --- |
| `index.html` | Основная разметка, контакты и навигация |
| `lib/projects.ts` | Данные основных проектов |
| `projects.js` | Карточки и выбор проектов |
| `additional-work.js` | AST Group, LeadFlow, дизайн-постеры и разделы галереи |
| `languages.js` | Переводы и выбор языка |
| `style.css`, `reference.css`, `motion.css` | Оформление и адаптивная композиция; стили подключаются в этом порядке |
| `experience.js`, `reference.js`, `motion.js` | Canvas, взаимодействия и анимации |
| `sound.js` | Управление звуком |
| `assets/design/` | Исходные изображения дизайн-работ |
| `assets/previews/` | Локальные превью интерфейсов |
| `app/` | Маршруты Next.js и клиентский мост анимации |
| `scripts/prepare-next.mjs` | Подготовка разметки, ресурсов и скриптов перед запуском |

Каталог `public/` и файл `app/portfolio-markup.ts` генерируются из исходных файлов. Правки разметки делайте в `index.html`.

Звук запускается после первого взаимодействия, согласно ограничениям браузеров. Выбранный язык и настройка звука хранятся локально в браузере. Формы сторонних демо и интеграции отдельных проектов зависят от соответствующих сайтов и репозиториев.

`san-portfolio.zip` сохранён как первоначальный архив; актуальная версия проекта находится в исходниках этого репозитория.
